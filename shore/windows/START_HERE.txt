ARGO SHORE STATION FOR WINDOWS 10/11
START HERE
================================================================================

Welcome! You're looking at the Windows setup files for the Argo shore station
(LoRa receiver + Web Dashboard).

================================================================================
QUICK START - 3 STEPS
================================================================================

1. Install WSL2 (PowerShell as Administrator):
   wsl --install -d Ubuntu-22.04
   (Restart computer when prompted)

2. Clone repository and run setup (Ubuntu terminal):
   cd ~ && git clone https://github.com/SensorsINI/argo.git
   cd argo && ./shore/setup_shore_station.sh

3. Launch shore station (Ubuntu terminal):
   ~/argo/shore/launch_shore_station.sh
   (Open browser: http://localhost:8081)
