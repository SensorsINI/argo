# Argo Simulator

This directory contains simulation-related code and configurations for the Argo sailboat project.

## Documentation

For complete simulation setup and usage instructions, see the main simulation guide:

**[📖 Simulation Guide](../docs/SIMULATION.md)**

The guide covers:
- Quick start instructions
- Keyboard control setup
- Foxglove Studio visualization
- Configuration parameters
- Troubleshooting

## Contents

- `sailboat-playground/` - Physical simulator submodule (sailboat-playground)
- `customizations/` - Custom boat and environment configurations

## Quick Start

1. Start the simulation: `asim --mock`
2. (Optional) Start keyboard control in another terminal: `asimkb`
3. Connect Foxglove Studio to `ws://localhost:8765`

See the [Simulation Guide](../docs/SIMULATION.md) for detailed instructions.
